# icecream

紅茶屋台の注文アプリ。茶葉5種、スパイス3種、渋み3段階を選択できます。

### 価格の仮定（課題用・税抜）

仕入れ価格は未調査。1杯250mlの茶葉・カップ・ふた・無料サービス・水・燃料・廃棄分を含む変動原価を仮定しています。

| 茶葉 | 販売価格 | 想定変動原価 | 1杯の差額 |
|---|---:|---:|---:|
| アールグレイ | 400円 | 130円 | 270円 |
| レディグレイ | 450円 | 150円 | 300円 |
| イングリッシュブレックファスト | 400円 | 130円 | 270円 |
| ダージリン | 500円 | 180円 | 320円 |
| プリンス オブ ウェールズ | 450円 | 150円 | 300円 |

スパイスは1種類50円、想定原価10円。渋みの調整は無料です。
出店料25,000円だけを固定費とすると、差額270円の商品で93杯が回収目安です。人件費・機材費などは別途必要です。

消費税は演習に合わせて10%・1円未満切り捨て。注文票には注文時の選択内容を保存します。
